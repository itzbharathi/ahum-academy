# AHUM Academy Website

A responsive one-page website for AHUM Academy, New Perungalathur, Chennai.

## Before publishing
1. Replace `https://www.example.com/` in `index.html`, `robots.txt`, and `sitemap.xml` with your real domain.
2. Add a Google Search Console property for the real domain and submit `/sitemap.xml`.
3. Create/claim the official Google Business Profile for AHUM Academy and keep the name, address, phone and website consistent.
4. Replace any wording that does not exactly match the academy's current services.
5. Add genuine photos, student reviews and official social links only after you have them.

## Publishing
Upload `index.html`, `robots.txt`, and `sitemap.xml` to your web host. This site uses no build system and can be hosted on any standard static web host.
